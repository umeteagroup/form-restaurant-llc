# Restaurant LLC Formation Execution SOP

Use this reference when operating portals, filing forms, paying fees, downloading records, or updating the closing binder. Keep all facts company-specific, but keep the process reusable.

## Operating Rules

- Verify current official requirements before relying on fees, deadlines, forms, filing rules, or permit requirements.
- Ask for only the missing facts needed for the next action. Prefer a Markdown intake questionnaire for owners.
- Do not store sensitive identity, payment, bank, password, MFA, SSN, full DOB, or ID-image data in chat or files.
- Stop before every final submit, payment, certification, or government attestation and ask for explicit confirmation.
- After each submission/payment/download, update the execution checklist, missing-items plan, portal tracker, and closing binder index.
- Use screenshots and short markdown summaries to preserve evidence when PDFs are unavailable.

## Standard Package Layout

Create one folder per company. Suggested subfolders:

- `official-ca-sos-downloads/`
- `official-irs-downloads/`
- `company-records/`
- `cdtfa/`
- `<city>-business-license/`
- `<county>-health-permit/`
- `ftb/`
- `edd-payroll/`
- `insurance/`
- `banking/`

Use clear names with sequence numbers, for example:

- `01-articles-of-organization-filed.pdf`
- `02-business-entity-filing-acknowledgment.pdf`
- `01-ein-assignment-success-page-print.pdf`
- `01-sellers-permit.pdf`
- `02-application-submitted-confirmation.md`
- `03-payment-receipt.md`

## Status Vocabulary

Use these statuses consistently:

- `Not started`
- `Prepared`
- `Submitted / pending review`
- `Paid / pending approval`
- `Approved / archived`
- `Blocked`
- `Not applicable`

## Sequence

1. Build intake and missing-items list.
2. Generate draft package.
3. File CA SOS Articles.
4. Download Articles, acknowledgment, welcome letter, and receipt.
5. Apply for EIN after state entity exists.
6. Save EIN assignment page or CP575. If CP575 is unavailable, note whether a 147C/confirmation letter may be needed later.
7. File CA Statement of Information.
8. Generate/sign operating agreement, resolutions, membership ledger, contribution schedule, and bank/CPA handoff.
9. Register CDTFA seller's permit.
10. Apply for city business license and pay when invoiced.
11. Start county health permit / food facility plan check.
12. Track FTB annual LLC tax and return obligations.
13. Set up payroll, workers' comp, insurance, bank account, and vendor onboarding.
14. Assemble and QA closing binder.

## CA SOS

Capture:

- Entity name
- Entity/file number
- Filed date
- Filing acknowledgment
- Payment receipt
- Statement of Information file number and receipt

If the portal download fails, use an external browser or user-provided downloads and rename files into `official-ca-sos-downloads/`.

## IRS EIN

IRS EIN has no reusable portal account. Save immediately after assignment.

Capture:

- EIN
- Legal name
- Name control if shown
- Success page PDF/screenshot
- CP575 if available

If only the success page is saved, record that banks/vendors may later request CP575 or IRS 147C.

## CDTFA Seller's Permit

Common data:

- Legal name, DBA, EIN, CA SOS number
- Principal/mailing/business location addresses
- NAICS/business activity
- Monthly projected sales and taxable sales
- Supplier info if requested
- Owner/officer/responsible-party info entered directly by authorized user when sensitive

Capture:

- Application confirmation number
- Sales and Use Tax account number
- Seller's Permit location ID
- Permit number and start date
- Permit PDF or rendered print view
- CDTFA correspondence messages

Notes:

- CDTFA may show "submitted and being processed" while status already lists approved permit.
- The profile Home accounts table may lag behind the Registration Status result.
- If a PDF opens in the browser viewer, first try saving the network response. If that saves viewer HTML, export the page to PDF and keep a screenshot.

## City Business License

Common data:

- DBA and legal name
- Business address and mailing address
- Ownership type
- Business activity
- Employee count
- Gross receipts estimate
- Start date in city
- EIN
- SB205/stormwater answer
- Residential/home-occupation answer
- Officer/emergency contact

Capture:

- Application confirmation number
- Account number and PIN if provided
- Payment due email amount
- Payment receipt confirmation
- Expiration date shown
- Final business license certificate after city/planning approval

Do not record temporary portal passwords in normal notes. If a receipt page displays a password, note that it must be stored in a password manager.

## Health Permit / Food Facility

Do not assume health permit requirements from another county. Gather:

- Store address and jurisdiction
- Menu and preparation methods
- Floor plan and equipment list
- Lease/buildout status
- Food safety manager/handler records
- Water/ice, refrigeration, sinks, dishwashing, storage, waste, grease/wastewater details
- Prior tenant or change-of-ownership facts

Track plan check, inspection, permit issuance, renewal, and certificate downloads separately.

## FTB / Payroll / Insurance / Bank

Track but usually coordinate with CPA, payroll provider, broker, and bank:

- FTB annual LLC tax / Form 3522 or Web Pay confirmation
- EDD employer payroll account
- Payroll provider onboarding
- Workers' comp policy
- General liability / property / umbrella insurance
- Bank account opening confirmation

## Closing Binder QA

Before saying the package is complete:

- Confirm each claimed file exists.
- Check PDFs/images are not blank.
- Confirm sensitive files are labeled if they contain passwords, card fragments, or personal identifiers.
- Update `03-formation-execution-checklist.md`.
- Update `24-post-formation-missing-files-and-registration-plan.md`.
- Update `25-government-portal-account-tracker.md`.
- Update `10-closing-binder-index.md`.

## Common Final Deliverables

The CPA-style six-file set usually maps to:

1. Articles of Organization
2. EIN CP575 or EIN assignment evidence
3. Operating Agreement
4. Membership Ledger
5. Statement of Information
6. Business Entity Filing Acknowledgment

Restaurant-specific add-ons often include:

- Seller's permit
- City business license application/payment/final certificate
- Health permit / inspection records
- FTB payment confirmation
- Payroll/EDD confirmation
- Workers' comp and insurance certificates
- Banking handoff and bank confirmation
