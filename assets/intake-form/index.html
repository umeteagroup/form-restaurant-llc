Restaurant LLC Intake

Collect the non-sensitive details needed to prepare a California restaurant LLC formation package. Nothing is uploaded; the form exports a local JSON file for the package generator.

Step 1 of 7
Do not enter SSNs, passport numbers, full dates of birth, bank passwords, or payment card details. Attorney and CPA review are recommended before signing or filing.

Company

Use the legal LLC name if known. Alternate names help if the first choice is unavailable.

Brand

If the public restaurant name differs from the LLC legal name, the company may need a DBA or fictitious business name filing.

Members

List owners, their expected ownership percentages, and who can sign for the company.

Locations

Add confirmed stores or target locations. City and county drive permit requirements.

Operations

These answers shape tax, seller's permit, payroll, insurance, and restaurant permit checklists.

Execution Scope

Choose which execution items should be included in the generated formation package.

Review and Export

Export the JSON file and run the package generator. You can also import a prior JSON file to keep editing.

Suggested command after export: form-restaurant-llc/scripts/generate_package.py --generate pilot-company-intake.json --out pilot-formation-package
